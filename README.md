## 🌌 Overview

M31-Agent is your AI-powered coding companion for Visual Studio Code, designed to enhance your development workflow with natural language understanding and AI assistance. It supports code generation, explanation, navigation, and more, powered by OpenRouter AI.

---

## 🚀 Key Features

- 💬 AI Chat: Natural conversations about your code inside VS Code.
- ✍️ Code Generation: Generate code snippets, functions, and modules.
- 🔍 Code Explanation: Understand complex code with clear explanations.
- 🖥️ Terminal Commands: Generate and run terminal commands via natural language.
- 🧭 Codebase Navigation: Easily find files, functions, and classes.
- 🌐 Multi-Language Support: Works with all major programming languages.

---

## 📥 Installation

Install M31-Agent easily from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=m31lab.m31-agen):

1. Open VS Code and go to the Extensions view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **M31-Agent**.
3. Click **Install**.

---

## ⚡ Quick Start

1. Get an OpenRouter API key from [openrouter.ai](https://openrouter.ai/).
2. Configure the API key in M31-Agent settings (`Ctrl+Shift+P` → *M31-Agent: Configure Settings*).
3. Activate M31-Agent via the status bar icon or command palette.
4. Start chatting, generating, or explaining code!
